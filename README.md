🎯 Today’s Study Focus

Today’s Study Focus is a simple, student-friendly web application designed to help learners decide what to study today without feeling overwhelmed.

Instead of trying to do everything, the tool analyzes each subject based on difficulty, urgency, and confidence level, then generates a clear, focused study plan with time distribution.

This project was built with the goal of reducing study stress and helping students focus on what truly matters.

🚀 Live Demo

👉 [The Study Planner](https://today-study-focus.netlify.app/)

💡 Why This Project Matters

Many students struggle with:

Feeling overwhelmed by too many subjects

Not knowing which subject deserves more time

Wasting study hours on low-priority tasks

This project solves that by:

Turning subjective feelings into a simple priority score

Automatically selecting the top 3 subjects to focus on

Distributing study time fairly and logically

Encouraging calm, intentional studying

🧠 How It Works

The user enters:

Subject name

Difficulty level

Urgency (e.g. exam soon or not)

Confidence level

The user sets total available study time (in hours)

The app:

Calculates a priority score for each subject

Sorts subjects by importance

Suggests:

Top subjects to focus on today

Time (in minutes) for each

Subjects that can be postponed

🔍 Algorithm Overview

The priority score is calculated using:

priority = difficulty × urgency × (4 - confidence)

This ensures:

Harder subjects get more attention

Urgent exams are prioritized

Subjects with low confidence receive more study time
